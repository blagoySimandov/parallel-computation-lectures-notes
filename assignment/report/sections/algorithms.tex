\section{Algorithms}

The four selected algorithms are \textbf{Direct Sort}, \textbf{Bucket Sort}, \textbf{All-to-All Bucket Sort}, and \textbf{Odd-Even Transposition Sort}.

Direct Sort, Bucket Sort and Odd-Even Sort were all "mandatory" for the assignment and
The selected optional one is All-to-All Bucket Sort.

For each algorithm we will compare its perfomance when parallerized against a single thread implementation (running the algorithm with NP=1)
At the very end we wil also compare the algorithms side by side.

All provided images and graphs were generated from running the experiments and loading them into the python libraries polars and altair.
For more details around the graph generation code check out the github repo \url{https://github.com/blagoySimandov/parallel-computation-lectures-notes}
And more specifically the `assignment` folder.

For the sake of consistency and correctness all benchmarks were run 5 times and the median time was used.
The average was not used due to concerns that outliers might skew the results.
